# Library

These are the PDFs collected while researching `../measures-literature.md`,
gathered from the research agents' downloads on 2026-09-23. File names follow
`Authors_Year_Title.pdf`. The letter after each entry names the report in
`../sources/` that cites the paper and gives its full, verified reference.

The PDFs are git-ignored by the repository's `*.pdf` rule. Only this index is
tracked. Several are publishers' versions and must not be redistributed.

Many entries are not the published version of the paper. They are arXiv
versions, author manuscripts or working papers, noted after each file name.
The Krakauer file is the 2014 arXiv version of the 2020 paper, which may
differ from it.
