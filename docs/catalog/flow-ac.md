# Flow artificial chemistry

`flow-ac` · *Kreyssig & Dittrich, 2011*

*Also known as:* *reaction flow artificial chemistry*

What happens when molecules are carried rather than stirred. An ordinary reaction network is placed in a two-dimensional domain and every molecule is advected along a vector field, reacting only with neighbours within a radius. Transport alone then produces strongly inhomogeneous distributions - patches, and a shell of one species around a core of another - that the same network could never show when well mixed. The complement to swarm chemistry: here motion is imposed from outside rather than generated by the particles.

**S — molecules** (explicit): ordinary molecular species placed in a 2D domain and moved along a vector field

**R — reactions** (explicit, arity [1, 2, 3]): Book figure 11.23 network (a, b, c, d): a + b -> a + 2b ; a + d -> a + 2d ; b + c -> 2c ; c -> b ; b + d -> c ; b -> ; c -> ; d -> . Molecules move x -> x + V(x) each iteration and react only with neighbours within a radius.

## Published phenomena

What the literature reports this model produces. Whether the generator reproduces each one is recorded in the decisions below.

- strongly inhomogeneous species distributions produced purely by transport (patches of b in the swirl)
- a membrane of m around a producer core, matching the organisations {m} and {m, p1, p2, p3}
- two compartments forming from rock-scissors-paper competitors

## Decisions

Every gap, ambiguity or erratum in the sources, and how Chemart resolved it. Read this before quoting a number from this entry.

- The book gives no reactions. The networks R1, R2 and R3 are the paper's; R1's mass-action form is confirmed by the paper's PDE reaction terms (all k = 1), which the tests reproduce. The fourth example (E. coli central sugar metabolism, 92 species and 198 reactions) is not reproduced in the paper and is not offered.
- R2 is printed as alpha p1 + beta p2 + gamma p3 -> m for alpha, beta, gamma in {0, 1}. The all-zero case (-> m) is excluded, because with it the empty set would not be closed, contradicting the paper's organisations O = {{}, {m}, {m, p1, p2, p3}}.
- Vector fields and simulation settings (molecules n, initial radius rad, reaction radius r, reacting fraction u, iterations) are recorded per example in extras.space, as strings and numbers; Chemart does not simulate them. The swirl field's square roots were lost in the PDF text and are read as V1 = (1/sqrt 2)((1 - sqrt 2) x - y, x + (1 - sqrt 2) y), an inward spiral. For the swirl example the paper states both 2500 starting molecules and n = 1600; 2500 is recorded.
- The previous parameters reactions, flow_field, diffusion and n_species are replaced by `example` and `k`: the paper uses flow instead of diffusion, and the networks are fixed per example. R2 and R3 carry no rates in the paper; they use the same k.

## Notes

Complements Swarm Chemistry: here motion is external and passive. Together they cover the two ways space enters an AC.
