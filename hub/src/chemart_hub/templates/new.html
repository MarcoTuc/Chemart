How sharing works here

This hub is built from a GitHub repository. chemart push and push_to_hub open a pull request that adds your folder under repos/<your GitHub name>/<name>/; they need the GitHub CLI (gh auth login once). Without it, they write the folder for you and print the steps to open the pull request by hand.

A check runs on every pull request: the files must form a valid repo, a chemistry must pass chemart check, and you may only change your own namespace. Once a maintainer merges it, the site rebuilds and your chemistry is on the shelf.
